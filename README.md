# Tecno Store

E-commerce de productos de tecnología. Proyecto final de la diplomatura de React.

## Tecnologías

- React
- Vite
- JavaScript

## Instalación

1. Clonar el repositorio
2. Entrar a la carpeta del proyecto
3. Instalar las dependencias:

```
npm install
```

4. Ejecutar el proyecto:

```
npm run dev
```
